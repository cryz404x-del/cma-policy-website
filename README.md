# CMA Practical Skills Assessment Website

A responsive website for the CMA Practical Skills Assessment Policy-Layer Supplement.

## Files

- index.html
- style.css
- script.js
- netlify.toml

## Deploy to Netlify

1. Log in to Netlify.
2. Click **Add new site**.
3. Choose **Import from GitHub**.
4. Select this repository.
5. Click **Deploy site**.

No build command is required.
